# סקיל החיפוש בעברית ל-Claude Code

בודקים בפקודה אחת מה תשובות ה-AI של גוגל אומרות על העסק שלכם, את מי הן מציגות במקומכם ומה חסר באתר.

הגרסה הישראלית נבנתה על ידי **נתנאל אסטריכר** - ייעוץ, הדרכות והרצאות AI לעסקים. עוד מדריכים וכלים באתר [netaneles.com](https://www.netaneles.com).

## מה יש כאן

הקובץ `search-skill-il.zip`, ובתוכו קובץ אחד עם שלושה סקילים:

- הפקודה `/search` - קוראת את האתר ואת תשובות ה-AI של גוגל לשאלות הלקוחות, ומריצה 12 בדיקות. בסוף מתקבל דוח בעברית עם רשימת תיקונים.
- הפקודה `/search-fixer` - מנסחת את התיקונים שבחרתם, ומבצעת כל תיקון רק אחרי אישור שלכם.
- הפקודה `/search-tracker` - בודקת שוב את אותן שאלות ומראה לפני ואחרי.

## התקנה

1. מורידים את `search-skill-il.zip` ופותחים אותו.
2. באפליקציית Claude למחשב פותחים את הלשונית Code, בסשן שרץ על המחשב שלכם.
3. גוררים את הקובץ `search-skill-il.md` לחלון השיחה וכותבים: תתקין את זה.

מדריך מלא עם צילומי מסך והסבר על כל שלב: [netaneles.com/google-ai-answers-skill](https://www.netaneles.com/google-ai-answers-skill/)

## חשוב לדעת

- אף אחד לא שולט בתשובות של גוגל. התיקונים משפרים את מה שגוגל נשענת עליו, ולא מבטיחים מקום.
- שום דבר לא משתנה באתר או בפרופיל בגוגל בלי אישור שלכם לשינוי המדויק.
- הסקיל רץ רק ב-Claude Code, שדורש מנוי Pro, Max, Team או Enterprise.
